A small Go framework for Cloudflare Workers.

Build request handlers in Go, compile them to WebAssembly with TinyGo, and run them at the edge. The framework, examples, and build pipeline are open for inspection.

First run

Start from a working worker.

Install the CLI, scaffold an API, then run it locally with Wrangler.

go install github.com/phongsathornpt/tiny-worker/cmd/tiny-worker@latest tiny-worker new myworker cd myworker tiny-worker dev
